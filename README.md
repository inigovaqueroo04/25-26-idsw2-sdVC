# Análisis, diseño e implementación de [Breñotask](https://github.com/inigovaqueroo04/25-26-IdSw1-SdR)

Este proyecto aplica las disciplinas de análisis, diseño e implementación de la metodología RUP a **Breñotask**, un sistema de la SdR orientado a que familias y grupos puedan coordinar, asignar y seguir tareas compartidas en el día a día.
